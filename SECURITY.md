# Security policy

Alwikobra (Private-Code-Digid) repositories: OPS, Store, brain and hub.

## Reporting a vulnerability

Do not open a public issue. Use "Report a vulnerability" under the repository's Security tab (private vulnerability reporting). If that is unavailable, email the repository owner listed on the organisation profile.

Include the affected repository, branch, steps to reproduce and impact. Never include real customer data or live credentials.

## What to expect

- Acknowledgement within 3 working days.
- Triage and severity within 7 days; fixes for critical or high issues are prioritised ahead of feature work.
- Fixes land on `v3` first and reach production only through the owner's approval.

## Supported versions

Only the production branch (`ops-v2` for OPS, `Productions` for Store) and the `v3` integration branch receive security fixes.

## Secrets

Found a secret in code or history? Report it privately. Do not rotate or delete it before reporting so the exposure can be assessed.
